# 書類のファイル名整理（Dropbox）

## 対象フォルダ

- Dropbox の `/せんげん台/しゅう`
- 対象は、スキャナーが付けた数字だけの名前のファイル（例：`20261113172247258.pdf`）など、
  まだ命名ルールどおりになっていない新しい書類。
- すでにルールどおりの名前のファイルや、以前からある管理用ファイル
  （例：`五香未納金.pdf`、`せんげん台未納.pdf`、`電話番.CSV`）は触らない。

## 命名ルール

```
YYMMDD 会社名 書類の内容.拡張子
```

- **YYMMDD**：**書類に書かれている日付**（記入日・申込日・発注日・発行日・通知日など）。
  スキャンした日やフォルダに入れた日ではない。例：2026年11月13日 → `261113`
- **会社名**：取引相手の会社名。自社（株式会社ビジネスホテルしらさぎ、カルド各店）ではなく相手側。
  「株式会社」「有限会社」などは省いて短くする。例：株式会社メディア4u → `メディア4u`
- **書類の内容**：申込書・通知書・発注書・請求書・契約書・登録書など、大まかな種類がわかる名前。
- 区切りは**半角スペース**。
- 保存場所は元と同じフォルダ（名前だけ変える）。

例：
- `260901 メディア4u 企業情報登録書.pdf`
- `261013 メディア4u 利用申込書.pdf`
- `260915 グローバー 発注書.pdf`

## 手順

1. Dropbox コネクタで `/せんげん台/しゅう` を一覧表示し（recursive=false）、対象ファイルを決める。
2. 中身を読む。
   - まず Dropbox の `fetch` でテキスト抽出を試す。
   - スキャン PDF は文字が入っておらず空になることが多い。その場合は `download_link` で一時 URL を取り、
     スクラッチパッドに curl でダウンロード → `pdftoppm -r 110 -png` で画像化して目で読む。
   - ダウンロード先は `*.dropboxusercontent.com`。環境のネットワーク設定でこのドメインを許可している必要がある
     （ブロックされたら、環境設定の Allowed domains に `*.dropboxusercontent.com` を追加してもらう）。
3. 各書類の「日付・相手の会社名・書類の種類」を読み取り、新しいファイル名の案を表にしてユーザーに見せる。
   気になる点（申込者欄の不一致、日付が読み取りにくいなど）があれば一緒に伝える。
4. ユーザーの OK をもらってから、Dropbox の `move` で名前を変更する（file_id を使う）。
   完了まで `check_job_status` で確認する。
5. 結果を「元の名前 → 新しい名前」の表で報告し、作業用にダウンロードしたコピーは削除する。
